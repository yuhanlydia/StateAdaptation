Create a publication-ready overview Figure 1 for a top-tier ICASSP / NeurIPS
machine-learning paper titled: "Event-Adaptive Building Damage Assessment via
Post-Visual Residual Key-Value Test-Time Tuning (KV-TTT)."

The figure should explain a frozen vision-language model that, when deployed
to a never-seen disaster event, does not update any network weight. Instead,
from a handful of labelled post-event examples it discovers a low-rank
"corrective subspace" inside the language decoder's Key/Value activations,
and it learns only a few bounded scalar gates (64 in total) that reshape the
post-event image tokens along that subspace using a handful of test-time
gradient steps. The figure must actively show how a naive source model wastes
computation over the full context, how KV-TTT selectively decides which
evidence to inspect and which corrective direction to move along, how much
fitting budget to allocate, how a verifier confirms or returns the prediction,
and when evidence is sufficient to answer the damage question.
