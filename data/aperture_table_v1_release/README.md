# Aperture table v1 fixed data

This bundle contains the **555 distinct images actually selected** for the four-backbone table: 231 Camelyon17-WILDS hospital-2 patches and 324 PathMNIST-224 images. It also contains the exact fit, calibration, query, and split manifests used by the run. The manifests under `manifests/` retain the original machine paths and fingerprints as a historical record; `image_map.json` maps each path to a bundled image and records its byte SHA-256 and decoded-pixel SHA-256. Repeated support images across the two seeds are stored once.

To create portable manifests at another location, run `python3 data/aperture_table_v1_release/restore.py /your/path/aperture_table_v1`. This verifies all 555 image byte hashes, writes absolute paths to the bundled images, and updates the split content hashes for those paths. The output directory must be empty. Set `prepared_root` in the table config to that output directory. The original `source_files` fields remain in the split records as provenance; they are not local file requirements for `read_roles`.

`PATHMNIST_PROVENANCE.json` records the full PathMNIST-224 source checksum, including its match to the [official MedMNIST Zenodo record](https://zenodo.org/records/10519652). MedMNIST lists PathMNIST under [CC BY 4.0](https://medmnist.com/v2); please retain attribution to Kather et al. and MedMNIST when redistributing or reusing these images. `CAMELYON17_MIRROR_PROVENANCE.json` records the exact hospital-2 mirror revision and source shard checksums. Camelyon17-WILDS patches come from [WILDS](https://github.com/p-lambda/wilds/blob/main/wilds/datasets/camelyon17_dataset.py); consult its dataset notice and the [original Camelyon17 site](https://camelyon17.grand-challenge.org/) for reuse terms.

The 12.6 GB upstream PathMNIST NPZ and the full Camelyon17 population are not duplicated here. This bundle contains every image selected for this table and enough hashes to check the original upstream downloads. No model weights or access tokens are included.
