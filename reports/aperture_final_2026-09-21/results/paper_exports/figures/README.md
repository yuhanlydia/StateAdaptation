# Measurement-based final-round figures

Calibration bars: mean and sample SD across support seeds. No SD is fabricated for a single seed. Corruption and residual-dose curves use the fixed seed-0 probe, without error bars or query-selected parameters. Positive-temperature scaling preserves argmax, so raw and temperature-adjusted F1 coincide for a fixed arm. All LoRA schedules and all other comparators remain available in the CSV/LaTeX tables.
