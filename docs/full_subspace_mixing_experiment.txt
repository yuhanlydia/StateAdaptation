BOUNDED FULL-SUBSPACE KV MIXING: IMPLEMENTATION AND FIRST TEST
================================================================
Date: 2026-08-09

CHANGE
------
The original diagonal controller is

  Z' = Z + M * (Z B) diag(alpha * tanh(a)) B^T.

An optional full controller was added:

  Z' = Z + M * (Z B) A B^T,
  A  = alpha * R / (1 + ||R||_F).

Unlike the diagonal controller, A can rotate and mix the rank-dimensional
gradient directions. Its spectral norm is strictly below alpha because
||A||_2 <= ||A||_F < alpha. R=0 exactly reproduces the source model.
The original diagonal mode remains the default and old states remain loadable.

----------------------

INTERPRETATION
--------------
Full mixing improves support optimization and query NLL, confirming that the
extra directional expressivity is active. It does not improve macro-F1 in this
first test. At alpha=3 it overfits more strongly than diagonal mixing: support
loss and query NLL improve while macro-F1 and balanced accuracy decline.

Therefore full mixing is retained as an experimental, opt-in ablation via
--coefficient-mode full. It must not replace the diagonal default or be claimed
as a classification improvement without support-only regularization/model
selection and independent-event validation.

LOCKED CROSS-EVENT TEST (FULL TARGET QUERY)
-------------------------------------------
The alpha=0.5, lr=0.05, rank=5, steps=4 full-mixing configuration was then
locked and evaluated without tuning on three earlier non-improving events.

event    source F1  diagonal F1  full F1  full-source  source NLL  full NLL
-------  ---------  -----------  -------  -----------  ----------  --------
beirut     0.3953       0.3914    0.3763      -0.0191      1.2757    1.2257
congo      0.2518       0.2461    0.2982      +0.0464      1.7227    1.5898
haiti      0.3227       0.3239    0.3239      +0.0013      0.9105    0.9189
mean       0.3233       0.3205    0.3328      +0.0095      1.3030    1.2448

The cross-event result is mixed: one clear win (Congo), one regression
(Beirut), and one effectively unchanged event (Haiti). Congo damaged-class
recall remains zero; its gain comes mainly from destroyed recall increasing
from 0.12 to 0.21. Full mixing consistently behaves more like probability
recalibration than a reliable class-boundary adaptation method. It is not yet
supported as a new default.
